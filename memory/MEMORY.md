## 用户偏好

### SuperClaude 命令使用规则

当用户的任务或指令匹配以下场景时，应主动提示用户优先使用 `/sc:` 命令：

1. **需求不明确/头脑风暴** → 提示使用 `/sc:brainstorm`
2. **代码分析/安全扫描** → 提示使用 `/sc:analyze`
3. **深度网络研究/实时信息** → 提示使用 `/sc:research`
4. **项目排期/工作量估算** → 提示使用 `/sc:estimate`
5. **功能代码实现** → 提示使用 `/sc:implement`
6. **系统架构/API设计** → 提示使用 `/sc:design`
7. **测试执行/覆盖率分析** → 提示使用 `/sc:test`
8. **代码质量改进/性能优化** → 提示使用 `/sc:improve`
9. **问题诊断/Bug修复** → 提示使用 `/sc:troubleshoot`
10. **代码清理/死代码移除** → 提示使用 `/sc:cleanup`
11. **代码/概念解释** → 提示使用 `/sc:explain`
12. **文档生成** → 提示使用 `/sc:document` 或 `/sc:index`
13. **Git智能操作** → 提示使用 `/sc:git`
14. **PRD生成实施计划** → 提示使用 `/sc:workflow`

**提示格式示例**：
> 这个任务适合使用 `/sc:brainstorm` 来进行需求发现，建议优先使用吗？

**生效范围**：当前英语学习小程序项目 (english-app) 及未来所有项目。
