一、产品概述

一款面向全年龄段（3岁以上）的英语学习微信小程序，支持多机构/学校/家庭平台化接入。核心围绕英文绘本展开，提供跟读评分、AI出题、AI对话、听写等功能，帮助学生在真实语言环境中学习英语。

三、商业模式

版本描述
免费版 可访问平台官方基础绘本，每日跟读限 3 次
付费个人版（C端订阅） 解锁全部绘本、无限跟读、AI对话、听写功能
机构版（B端订阅） 按学生席位收费，校长统一管理账号

策略：Freemium — 免费功能吸引用户，付费功能转化留存。

四、用户角色与权限

角色登录方式核心权限
学生 微信一键登录 学习绘本、跟读打分、AI对话、听写、查看个人报告
家长 微信一键登录 绑定子女、查看报告、布置任务、收提醒、陪读模式
英语老师 账号密码登录 上传绘本、录制音频、管理班级、布置作业、查看班级数据
校长 账号密码登录 管理机构内老师账号、审核老师上传内容、查看机构数据报告、采购版权绘本
管理员 账号密码（H5后台） 审核机构入驻、平台合规终审、数据看板、系统配置

关键规则

  • 学生账号由老师或家长创建，低龄学生无需自行注册
  • 家长可绑定多个子女，一个学生可被多个家长绑定
  • 老师属于某机构，机构由管理员审核入驻
  • 内容审核两级：老师上传 → 校长初审 → 管理员合规终审
  • 一个机构有且只有一个校长账号（由管理员分配）
  • 权限采用 RBAC（基于角色的访问控制）

六、核心功能模块

MVP 功能（第一版）

1. 绘本管理

  • 内容来源：平台官方预置 + 老师上传 + 第三方版权库对接
  • 上传流程：老师上传图片（每页一张）→ 填写文字内容 → 录制/上传音频 → 提交校长初审 → 管理员合规审核 → 上架
  • 绘本属性：标题、封面、适读年龄、难度级别（L1-L6）、分类标签（自然/动物/生活/故事等）、来源类型
  • 页面属性：图片 + 文字 + 标准音频 + 单词高亮时间轴

2. 跟读打分（核心）

  • 学习流程：选择绘本 → 听标准音频 → 点击录音跟读 → 上传音频 → 讯飞语音评测 → 返回评分
  • 评分维度：发音准确度、流利度、语调/韵律、完整度 + 综合总分
  • 结果展示：雷达图四维展示、问题单词红色高亮 + 正确发音播放、历史趋势折线图
  • 异步处理：评分任务走 Redis 队列，避免 API 超时

3. AI 动态出题

  • 触发时机：完成一遍绘本跟读后触发
  • 题型：
    • 选择题：绘本内容理解（4选1）
    • 看图填词：给图片填入对应英文单词
    • 问答题：AI 提问，学生语音或文字回答
  • 出题逻辑：绘本文字内容 → Claude/OpenAI 按年龄/难度生成 → 缓存复用（同绘本不重复出题）→ 答题后 AI 解析 + 解释
  • 交互方式：根据学生年龄/题型自动切换语音或文字输入

扩展功能（后续版本）

4. AI 对话

  • 自由对话模式：学生用英语与 AI 随意聊天，AI 实时纠错并鼓励
  • 情景对话模式：预设场景（餐厅/超市/学校等），AI 扮演场景角色
  • 绘本对话模式：围绕当前绘本，AI 提问辅助理解
  • 技术流程：语音输入 → 讯飞 STT → Claude/OpenAI → TTS 语音播放

5. AI 听写

  • 流程：老师/平台设定词汇范围 → AI 朗读单词/句子 → 学生作答（低龄选字母拼写，高年级直接输入）→ 自动批改 + 错词记录
  • 智能复习：基于遗忘曲线定时推送复习提醒，错词关联绘本语境
  • 错词本：错误词汇自动归集，可随时复习

6. 学习数据分析

  • 学生视角：学习时长、跟读次数、平均得分趋势、发音弱项词汇 Top10、词汇掌握图谱
  • 家长/老师视角：每日打卡情况、班级强弱项热力图、个人 vs 班级均值对比
  • 自动推送：每周生成学习周报，通过微信服务通知发送

7. 家长陪读模式

  • 家长与学生同步学习同一绘本
  • 家长可给孩子布置指定绘本学习任务
  • 接收子女学习提醒（未打卡、成绩下降等）

七、数据模型

-- 用户体系
users:               id, openid, phone, role, institution_id, created_at
institutions:        id, name, status(pending/active), principal_id
parent_student:      parent_id, student_id
teacher_class_student: teacher_id, class_id, student_id

-- 绘本体系
books:      id, title, cover_url, age_range, level(L1-L6), source, status, institution_id, created_by
book_pages: id, book_id, page_no, image_url, text_content, audio_url
book_words: id, page_id, word, start_ms, end_ms

-- 学习记录
reading_records:  id, student_id, book_id, page_id, audio_url,
                  score_total, score_pronunciation, score_fluency,
                  score_intonation, score_completeness, created_at
quiz_records:     id, student_id, book_id, question, answer, is_correct
dialogue_records: id, student_id, mode, messages(JSON), created_at
dictation_records: id, student_id, word, user_input, is_correct, created_at

-- 词汇体系
vocabulary:        id, word, definition, phonetic
student_vocabulary: id, student_id, word_id, status(new/learning/mastered), next_review_at
