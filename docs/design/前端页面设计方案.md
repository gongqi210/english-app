# 英语学习微信小程序 - 前端页面设计方案

**项目名称**：我AI学英语
**版本**：v1.0
**日期**：2026-03-15
**状态**：前端设计完成

---

## 一、设计概述

### 1.1 设计目标

- 为3岁以上儿童提供友好的英语学习体验
- 支持多角色（学生、家长、老师、校长、管理员）
- 界面活泼、色彩丰富，适合儿童审美
- 操作简单，降低学习门槛

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **童趣性** | 圆润的图标、柔和的色彩、可爱的动画 |
| **易用性** | 大按钮、简单操作、直觉交互 |
| **一致性** | 统一的设计语言和交互模式 |
| **可访问性** | 考虑不同年龄段用户的需求 |

### 1.3 技术选型

| 端 | 技术栈 | UI组件库 |
|---|--------|---------|
| **小程序学生端** | 原生微信小程序 | Vant Weapp |
| **小程序家长端** | 原生微信小程序 | Vant Weapp |
| **小程序老师端** | 原生微信小程序 | Vant Weapp |
| **管理后台H5** | Vue 3 + Vite | Element Plus |

## 五、交互规范

### 5.1 手势操作

```
┌─────────────────────────────────────────────────────┐
│                   手势操作规范                      │
├─────────────────────────────────────────────────────┤
│                                                     │
│  👆 点击（Tap）                                      │
│  - 用于：按钮、卡片、列表项                          │
│  - 反馈：轻微缩放（scale: 0.98）                   │
│  - 时长：< 200ms                                   │
│                                                     │
│  👆👆 双击（Double Tap）                             │
│  - 用于：音频播放/暂停                              │
│  - 反馈：图标切换 + 轻微震动                        │
│                                                     │
│  👆 长按（Long Press）                              │
│  - 用于：录音按钮                                   │
│  - 反馈：按钮放大 + 声波开始动画                   │
│  - 提示：松开结束录音                               │
│                                                     │
│  ↔️ 左右滑动（Swipe）                               │
│  - 用于：绘本翻页、轮播图                           │
│  - 反馈：页面跟随手指移动                          │
│  - 边界：到达第一页/最后一页时弹性效果              │
│                                                     │
│  ⬇️ 下拉（Pull Down）                               │
│  - 用于：刷新列表                                   │
│  - 反馈：松手触发刷新动画                          │
│                                                     │
│  🔄 上拉加载（Pull Up）                             │
│  - 用于：加载更多                                  │
│  - 反馈：触发加载动画                              │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 5.2 动画规范

```
┌─────────────────────────────────────────────────────┐
│                   动画规范                          │
├─────────────────────────────────────────────────────┤
│                                                     │
│  ⏱️ 时间规范                                         │
│  ├── 快速交互：150ms（按钮点击、切换）              │
│  ├── 中速过渡：300ms（页面切换、弹窗）             │
│  └── 慢速动画：500ms（大型动效、成就展示）          │
│                                                     │
│  🎨 缓动函数                                         │
│  ├── 进入：ease-out（弹入、淡入）                   │
│  ├── 退出：ease-in（弹出、淡出）                   │
│  └── 循环：ease-in-out（摇摆、呼吸）               │
│                                                     │
│  ✨ 动效类型                                         │
│  ├── 按钮点击：scale(0.95) → scale(1)              │
│  ├── 页面进入：translateY(20px) → translateY(0)   │
│  ├── 弹窗：scale(0.9) → scale(1) + fade          │
│  ├── 录音声波：wave animation                      │
│  ├── 得分数字：countUp animation                   │
│  └── 徽章获得：bounce + sparkle                    │
│                                                     │
│  ⚡ 性能优化                                         │
│  ├── 使用 transform 和 opacity                      │
│  ├── 避免动画中触发重排                            │
│  ├── 复杂动画使用 Lottie                           │
│  └── 超过3s的动画设置 will-change                  │
│                                                     │
└─────────────────────────────────────────────────────┘
```
