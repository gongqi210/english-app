## 一、产品架构设计

### 核心观点：作业是"课后延伸"，不是独立功能

### 架构分层

```
┌─────────────────────────────────────────────┐
│                   平台层                     │
│  • 公共题库（官方）  • 公共绘本库            │
│  • AI能力（出题/评测/TTS）                 │
└─────────────────────────────────────────────┘
                        │
┌─────────────────────────────────────────────┐
│                   机构层                     │
│  • 机构私有题库   • 机构作业               │
│  • 机构数据（学生、班级）                  │
└─────────────────────────────────────────────┘
                        │
┌─────────────────────────────────────────────┐
│                   用户层                     │
│  • 绘本学习  • 作业完成  • 学习报告        │
└─────────────────────────────────────────────┘
```

### 功能整合

| 现有能力 | 作业中复用 |
|-----------|------------|
| 绘本内容 | 可作为作业素材 |
| 跟读评测 | 作业中的跟读题 |
| AI出题 | 作业题目来源 |
| TTS | 听力题音频 |
| 学习报告 | 整合作业数据 |

## 二、用户体验优化

### 目标：家长从"辅导者"变成"监督者"

| 痛点 | 解决方案 | 目标指标 |
|------|----------|----------|
| 陪孩子做作业累 | 自动化批改，即时反馈 | 家长参与从30分→5分 |
| 发音不准 | AI跟读评测 | 独立完成率80%+ |
| 不知道对错 | 做完即显示 | 无需家长判断 |

### 激励设计

- **游戏化闯关**：地图冒险、星星积分、徽章奖励
- **社交激励**：班级排行榜
- **自动提醒**：完成通知（推送给家长）

## 三、商业模式

### 定价策略

| 套餐 | 价格 | 功能 |
|------|------|------|
| 免费版 | ¥0 | 每天1份基础作业 |
| 基础版 | ¥30/生/年 | 作业+题库 |
| 高级版 | ¥50/生/年 | +AI批改+手写识别 |
| 定制版 | ¥80/生/年 | +专属题库+品牌Logo |

### 变现点

1. 作业量解锁
2. 高级题型（手写、听力）
3. 精品题库
4. 深度测评报告
5. 机构数据服务

## 四、技术难点解决方案

| 难点 | 解决方案 | 备注 |
|------|----------|------|
| 手写识别95%+ | 讯飞API+样本训练 | 允许家长辅助确认 |
| OCR题目导入 | OCR+GPT-4解析+人工校正 | 逐步优化 |
| 闯关游戏化 | Canvas 2D渲染 | 多种主题 |
| 多机构Logo | 登录时获取配置+动态渲染 | 缓存优化 |
