## 一、背景与痛点

### 1.1 核心痛点

| 用户角色 | 痛点 | 频次 |
|---------|------|------|
| **家长** | 陪伴时间成本高，每次作业需要全程陪同 | 高 |
| **家长** | 英语发音不标准，无法辅导孩子 | 高 |
| **家长** | 工作忙碌，没有时间陪孩子做作业 | 中 |
| **老师** | 作业批改工作量大，每个学生都要批改 | 高 |
| **老师** | 难以针对学生个体差异布置作业 | 中 |
| **老师** | 输入题目工作量大，需要题库管理 | 高 |
| **学生** | 传统作业形式枯燥，缺乏趣味 | 高 |
| **学生** | 不知道自己对错，即时反馈缺失 | 高 |

### 1.2 需求来源

参考作业形式：描红、连线、选择、填空、听力（见 `miniprogram/others/作业.png`）

## 三、功能模块拆解

### 3.1 题库管理模块（老师端 - 核心）

#### 3.1.1 题目管理
- **题目创建**：手动输入题目
- **题目编辑**：修改题目内容、答案、解析
- **题目删除**：删除单个或批量删除
- **题目导入**：
  - 图片OCR识别 → 自动生成题目
  - PDF解析 → 自动生成题目
  - Excel批量导入
- **题目审核**：待审核/已通过/已驳回

#### 3.1.2 题库分类
- **按题型**：描红、连线、选择、填空、听力、手写
- **按难度**：L1-L6
- **按知识点**：字母、单词、短语、句子、绘本
- **按来源**：自主创建、OCR导入、AI生成、官方题库

#### 3.1.3 题目属性
```json
{
  "id": "uuid",
  "type": "choice|fill_blank|listening|tracing|matching|handwriting",
  "content": "题目内容",
  "media_url": "图片/音频URL",
  "options": [{"key": "A", "value": "选项内容"}],
  "correct_answer": "正确答案",
  "explanation": "解析",
  "difficulty": 3,
  "knowledge_points": ["字母", "元音"],
  "age_range": "3-5",
  "source": "ocr_import|manual|ai_generate|official",
  "status": "pending|approved|rejected",
  "created_by": "teacher_id",
  "institution_id": "机构ID"
}
```

### 3.2 作业创建模块（老师端）

#### 3.2.1 作业模板库
- 预置常用作业模板
- 模板分类：字母、单词、句子、绘本、专项练习
- 模板难度分级：L1-L6
- 模板支持题型：描红、连线、选择、填空、听力

#### 3.2.2 作业设计器
- 从题库拖拽式选择题目
- 闯关顺序设置（游戏地图）
- 完成时间限制
- 截止日期设置
- 发送对象选择（班级/个人）

#### 3.2.3 练习册导入（OCR/PDF）
- **图片拍照 → OCR识别 → 自动生成题目 → 人工校正 → 题目入库**
- **PDF导入 → 内容解析 → 题目生成 → 人工校正 → 题目入库**

### 3.3 作业完成模块（学生端）

#### 3.3.1 游戏闯关模式（核心特色）
- **地图式关卡选择**：冒险岛、星球探险、城堡闯关等主题
- **每关包含1-3种题型**
- **完成后解锁下一关**
- **星星/积分/徽章激励**
- **班级排行榜**

#### 3.3.2 支持题型

| 题型 | 描述 | 自动批改 | 手写识别准确率 | 适用年龄 |
|------|------|---------|---------------|---------|
| **描红题** | 在示范字母/单词上书写 | 轨迹判定 | 95%+ | 3-6岁 |
| **听力题** | 听音频选图片 | ✅ | - | 全年龄 |
| **连线题** | 图片与单词连线 | ✅ | - | 4-8岁 |
| **选择题** | 看图/文字选答案 | ✅ | - | 全年龄 |
| **填空题** | 看图填写单词 | AI判断 | 95%+ | 6岁+ |
| **手写题** | 书写单词/句子 | 手写识别 | 95%+ | 6岁+ |

#### 3.3.3 年龄适配

| 年龄段 | 界面特点 | 输入方式 |
|--------|---------|---------|
| 3-5岁 | 图形化、大按钮、语音辅助 | 语音/选择/描红 |
| 6-8岁 | 图文结合 | 选择/简单输入/手写 |
| 9岁+ | 文字为主 | 键盘输入/手写 |

### 3.4 作业批改模块

#### 3.4.1 自动批改
- 选择题：100%准确
- 听力题：100%准确
- 连线题：自动判定
- 填空题：AI语义匹配（支持大小写、简写）
- **手写识别：≥95%准确率**

#### 3.4.2 AI辅助
- 发音评测：跟读打分
- 手写识别：拍照识别手写内容（目标95%+）
- 错误分析：智能分类错误类型

### 3.5 作业查看模块

#### 3.5.1 家长端
- 作业完成提醒（推送）
- 完成进度查看
- 成绩单查看
- 薄弱点提示
- 详细答题记录

#### 3.5.2 老师端
- 提交情况统计
- 完成率/正确率分析
- 典型错误汇总
- 作业布置历史
- 班级对比数据

## 四、新增功能：新生测评

### 4.1 测评目的
- 评估新生英语基础水平
- 自动分配到合适的班级/难度
- 为个性化学习提供依据

### 4.2 测评内容
- 听力测试：听音识图
- 口语测试：跟读评分
- 词汇测试：看图识词
- 理解测试：简单问答

### 4.3 测评流程
```
新生入学
    ↓
1. 登录 → 收到测评邀请
    ↓
2. 进入测评页面
    ↓
3. 依次完成各板块测试
    ↓
4. AI自动评分
    ↓
5. 生成测评报告
    ↓
6. 推荐适合的学习路径和班级
```

### 4.4 测评报告
- 综合评分
- 各能力维度得分
- 推荐级别（L1-L6）
- 推荐课程/绘本
- 薄弱项建议

## 六、技术实现难点

### 6.1 手写识别（难点 ⭐⭐⭐）

**准确率要求：≥95%**

**描红判定**
- 问题：判断用户书写轨迹是否在规定区域内
- 方案：Canvas获取轨迹坐标，与预设区域进行碰撞检测

**手写识别**
- 问题：将手写的英文字母/单词识别为文本
- 方案：
  - 客户端：Canvas获取书写图像
  - 服务端：讯飞手写识别API
  - 目标准确率：95%+

### 6.2 OCR题目导入（难点 ⭐⭐⭐⭐）

**支持：图片OCR + PDF解析**

**流程**
```
图片拍照/PDF上传 → OCR识别 → AI题目解析 → 人工校正 → 生成题目
```

**技术方案**
- 腾讯云OCR文字识别（印刷体）
- 讯飞OCR（教育场景优化）
- GPT-4题目结构化解析
- 预留人工校正入口

### 6.3 听力题实现

- 预录制听力素材库
- 音频预加载（避免播放延迟）
- 科大讯飞TTS合成（动态生成）
- 音频与图片时序控制

### 6.4 游戏化闯关

- 地图可视化设计（冒险岛/星球/城堡主题）
- 进度持久化存储
- 积分/徽章/排行榜系统
- 动画和音效

## 九、产品机会点

1. **减少家长参与** - 全自动化批改，即时反馈，减少家长辅导需求
2. **练习册数字化** - 老师工作量大幅降低，一键生成数字作业
3. **题库复用** - 一次输入，反复使用
4. **游戏化设计** - 闯关、积分、徽章，提升学习兴趣
5. **个性化学习** - 基于测评结果智能推荐
6. **机构品牌** - Logo定制，增强归属感
