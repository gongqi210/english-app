# 英语学习微信小程序 - 产品需求规格说明书

**项目名称**：我AI学英语
**版本**：v1.0
**日期**：2026-03-15
**状态**：需求分析完成

---

## 一、产品概述

### 1.1 产品定位

一款面向全年龄段（3岁以上）的英语学习微信小程序，支持多机构/学校/家庭平台化接入。核心围绕英文绘本展开，通过跟读评分、AI出题、AI对话等功能，帮助学生在真实语言环境中学习英语。

### 1.2 目标用户

| 用户角色 | 年龄/特征 | 核心诉求 |
|---------|----------|---------|
| 学生 | 3岁+，幼儿→成人 | 游戏化学习、获得成就感 |
| 家长 | 25-45岁 | 孩子学习效果、节省陪读时间 |
| 老师 | 英语教学从业者 | 减轻教学负担、班级管理 |
| 校长/机构管理者 | 培训机构负责人 | 运营效率、品牌形象 |
| 管理员 | 平台运营方 | 合规管理、数据看板 |

---

## 二、用户角色与权限

### 2.1 角色定义

| 角色 | 创建方式 | 登录方式 | 核心权限 |
|------|---------|---------|---------|
| 学生 | 老师/家长创建 | 微信一键登录 | 学习、跟读、打卡、查看个人报告 |
| 家长 | 微信一键登录 | 微信一键登录 | 绑定子女、查看报告、布置任务、陪读 |
| 老师 | 账号密码注册 | 账号密码 | 上传绘本、录制音频、管理班级、布置作业 |
| 校长 | 管理员分配 | 账号密码 | 审核内容、管理老师、查看机构数据 |
| 管理员 | 系统初始化 | 账号密码 | 审核机构、平台合规终审、系统配置 |

### 2.2 权限规则

- 学生账号由老师或家长创建，无需自行注册
- 家长可绑定多个子女，一个学生可被多个家长绑定
- 老师属于某机构，机构由管理员审核入驻
- 内容审核两级：老师上传 → 校长初审 → 管理员终审
- 一个机构有且只有一个校长账号

## 三、功能需求

### 3.1 MVP功能（第一版）

#### 3.1.1 用户模块

**功能清单：**
- [ ] 微信一键登录（学生、家长）
- [ ] 账号密码登录（老师、校长、管理员）
- [ ] 用户信息完善（头像、昵称、年龄）
- [ ] 角色切换（家长可切换查看子女账号）
- [ ] 机构入驻申请（老师/校长发起）
- [ ] 班级管理（老师创建班级、添加学生）

#### 3.1.2 绘本管理模块

**功能清单：**
- [ ] 绘本列表：分类浏览、难度筛选、搜索
- [ ] 绘本详情：封面、简介、难度、适读年龄
- [ ] 绘本阅读：逐页展示、图片+文字+同步音频
- [ ] 绘本上传（老师）：图片批量上传、文字编辑、音频上传
- [ ] 绘本审核：状态流转（待审核→初审→终审→上架/驳回）
- [ ] 绘本推荐：基于年龄、历史学习

**数据模型：**
```
books: id, title, cover_url, age_range, level(L1-L6), tags[], source,
       status(draft/pending/reviewing/published/rejected),
       created_by, institution_id, created_at

book_pages: id, book_id, page_no, image_url, text_content,
            audio_url, duration_ms

book_words: id, page_id, word, start_ms, end_ms, phonetic
```

#### 3.1.3 跟读打分模块（核心功能）

**功能清单：**
- [ ] 标准音频播放：可暂停、拖动、调节速度、循环单句
- [ ] 录音功能：按下录音、松开停止、可重录
- [ ] 音频上传：分片上传、进度显示
- [ ] 语音评测：调用讯飞API，返回四维评分
- [ ] 结果展示：雷达图、问题单词高亮、正确发音播放
- [ ] 历史记录：每次跟读记录、可回放、趋势图

**评分维度：**
- 发音准确度（pronunciation）：0-100
- 流利度（fluency）：0-100
- 语调/韵律（intonation）：0-100
- 完整度（completeness）：0-100
- 综合总分（total）：加权计算

**技术要求：**
- 评分任务走Redis队列异步处理
- 评分结果5秒内返回

#### 3.1.4 AI动态出题模块

**功能清单：**
- [ ] 触发条件：完成一遍绘本跟读后自动触发
- [ ] 选择题生成：根据绘本内容生成4选1理解题
- [ ] 填词题生成：看图填词、单词拼写
- [ ] 题目缓存：同绘本不重复出题
- [ ] 答案解析：AI给出详细解释
- [ ] 语音/文字输入：根据年龄自动切换

**出题规则：**
- 每次3-5道题
- 难度与绘本级别匹配
- 年龄适配：幼儿以语音为主，高年级可文字输入

#### 3.1.5 学习报告模块

**功能清单：**
- [ ] 个人报告：学习时长、跟读次数、得分趋势
- [ ] 弱项词汇：发音困难单词Top10
- [ ] 历史趋势：折线图展示进步曲线
- [ ] 成就系统：积分、徽章、等级

### 3.2 扩展功能（v1.1+）

#### 3.2.1 AI对话模块

- [ ] 自由对话：开放式英语聊天，实时纠错
- [ ] 情景对话：预设场景，AI扮演角色
- [ ] 绘本对话：围绕绘本内容提问
- [ ] 语音输入/输出

#### 3.2.2 AI听写模块

- [ ] 听写任务创建：设定词汇范围
- [ ] AI朗读：单词/句子朗读
- [ ] 自动批改：即时返回对错
- [ ] 错词本：自动归集

## 四、商业模式

### 4.1 版本划分

| 版本 | 价格 | 功能 |
|------|------|------|
| 免费版 | ¥0 | 官方基础绘本、每日3次跟读 |
| 个人订阅 | ¥19/月或¥99/年 | 全部绘本、无限跟读、AI对话、听写 |
| 机构版 | ¥50/生/年 | 品牌定制、专属管理、班级管理 |

### 4.2 Freemium转化策略

- 限制免费版跟读次数（3次/天）
- 首次付费引导：完成5次学习后弹出
- 限时优惠：新用户首周5折
- 口碑传播：分享海报送会员

## 五、非功能性需求

### 5.1 性能要求

| 指标 | 要求 |
|------|------|
| 首屏加载 | <2秒 |
| 跟读评分响应 | <5秒 |
| 音频播放启动 | <1秒 |
| 并发支持 | 1000+机构、10万+学生 |

### 5.2 安全性要求

- 全站HTTPS传输
- 敏感数据（手机号）加密存储
- 支付对接微信支付官方API
- 内容审核：AI+人工双重机制
- 隐私合规：《个人信息保护法》

### 5.3 兼容性要求

- 微信版本：7.0+
- iOS：12+
- Android：8+

## 八、风险与建议

### 8.1 潜在风险

1. **AI内容质量**：AI出题可能存在逻辑错误，需人工抽检
2. **语音评测准确性**：儿童发音变异大，需优化模型
3. **合规风险**：儿童内容需严格审核
4. **版权问题**：绘本需确保版权授权

### 8.2 实施建议

1. 优先MVP功能，控制开发周期
2. 尽早申请API和资质
3. 建议先做小规模试点
4. 重视用户反馈快速迭代
